# Repository scope

Use this public repository to maintain released consumers and interfaces, the
case package, guard examples, and independent verification. Keep correctness and
security fixes for released APIs here.

Keep new candidate search or optimization methods, private evaluation campaigns,
and production, fleet, or deployment orchestration in private source. Do not add customer cases or configurations here.

Preserve published releases and history, source pins, reason semantics, and
working verification paths for existing consumers.
